# 宝塔面板部署（已有 Node）

> 适用：宝塔 Linux 面板 + 已经装好 Node.js。
> 本流程假设安装目录为 `/www/wwwroot/hpjyjmz/kimuzhi`（换成你自己的目录也能用，全文替换即可）。
> 项目**零第三方依赖**：不需要 `npm install`、不需要装数据库（用 Node 内置的 `node:sqlite`）。

---

## 第 0 步：确认 Node 版本（最关键）

```bash
node -v
```

| 输出 | 怎么做 |
|---|---|
| `v24.x`（推荐） | 直接往下走，参数不用改 |
| `v22.5` ~ `v22.x` | 能用，但**启动参数必须加 `--experimental-sqlite`**（见第 4 步） |
| `v22.4` 或更低、`v20.x` | **不能用**（没有内置 SQLite）。去宝塔「软件商店 → Node.js 版本管理器」装 Node 24 LTS，再在 Node 项目里选它 |

顺手确认一下仓库代码在不在、是不是最新：

```bash
cd /www/wwwroot/hpjyjmz/kimuzhi
git log --oneline -1        # 应看到最新提交
git status --short          # 最好什么都不输出
```

没有代码就先 clone：

```bash
cd /www/wwwroot/hpjyjmz
git clone https://github.com/wanliao/jmz.git kimuzhi
cd kimuzhi
```

---

## 第 1 步：建 `data` 目录（放数据库）

```bash
cd /www/wwwroot/hpjyjmz/kimuzhi
mkdir -p data
```

---

## 第 2 步：写 `.env`（配置 + 管理员账号）

> `.env` 被 `.gitignore` 排除，`git clone` / `git pull` **都不会**给你生成它，必须手动建一次。
> 它也不会被 git 覆盖，以后升级不用管。

```bash
cp .env.example .env
nano .env        # 或者用宝塔文件管理器双击编辑
```

按下面改（**只列需要动的**，其余保持默认）：

```ini
PORT=8787
HOST=127.0.0.1                 # 由 Nginx 反代；如果不用域名、想直接 IP:8787 访问就写 0.0.0.0
TIME_ZONE=Asia/Shanghai
DB_FILE=./data/kimuzhi.db
ADAPTER=http                   # 想先用假数据看界面就写 mock
API_KEY=                       # 接口服务在它后台设了访问密钥才填，没有就留空
ALLOW_LOCAL_MODE=1
AUTO_REFRESH_MINUTES=0
SETTLE_GRACE_MS=600000
ADMIN_USERNAME=admin
ADMIN_PASSWORD=换成你自己的强密码
```

要点：
- 环境变量优先级 **高于** `config/endpoints.json`，所以自定义项写这里最安全（升级不会冲突）；
- `ADMIN_USERNAME` / `ADMIN_PASSWORD` 只在**库里一个管理员都没有**时用于自动创建，之后改密码请走后台；
- 改完 `.env` 必须重启服务才生效。

---

## 第 3 步：给权限（宝塔常用 www 用户）

```bash
chown -R www:www /www/wwwroot/hpjyjmz/kimuzhi
chmod -R 755 /www/wwwroot/hpjyjmz/kimuzhi
```

---

## 第 4 步：在宝塔里建 Node 项目

**网站 → Node 项目 → 添加 Node 项目**，按下表填：

| 字段 | 填什么 |
|---|---|
| 项目名称 | `kimuzhi`（随便起） |
| 项目目录 | `/www/wwwroot/hpjyjmz/kimuzhi` |
| 启动文件 / 启动选项 | `server/index.js` |
| 项目端口 | `8787`（要和 `.env` 的 `PORT` 一致） |
| 运行用户 | `www` |
| Node 版本 | `24.x`（推荐） |
| 包管理器 / 安装依赖 | **不用装**（没有依赖，跳过 `npm install`） |
| 启动命令（如果面板要填完整命令） | `node --disable-warning=ExperimentalWarning server/index.js` |

> **Node 22.x 的话**启动命令改成：
> `node --disable-warning=ExperimentalWarning --experimental-sqlite server/index.js`

如果面板里有「运行目录 / 工作目录」，填 `/www/wwwroot/hpjyjmz/kimuzhi`（`.env` 和 `data/` 都是相对这个目录找的）。

建好点「**启动**」。

---

## 第 5 步：自检

```bash
curl http://127.0.0.1:8787/api/health
# 期望：{"ok":true,"data":{"status":"up",...}}

curl -s http://127.0.0.1:8787/api/config | head -c 300
# 期望：能看到 "announcement":"" 等字段

cd /www/wwwroot/hpjyjmz/kimuzhi
node scripts/smoke.mjs http://127.0.0.1:8787
# 期望：只读检查全部通过
```

看日志：宝塔 Node 项目里有「日志」按钮；或

```bash
tail -n 50 /www/wwwroot/hpjyjmz/kimuzhi/*.log 2>/dev/null
```

---

## 第 6 步：绑域名 + 反向代理 + HTTPS

1. **建站点**：网站 → 添加站点（纯静态即可，PHP 版本选「纯静态」），域名填你的域名；
2. **反向代理**：该站点 → 设置 → 反向代理 → 添加：
   - 代理名称：`kimuzhi`
   - 目标 URL：`http://127.0.0.1:8787`
   - 发送域名：`$host`
3. **SSL**：站点 → SSL → Let's Encrypt，勾选域名申请 → 开启「**强制 HTTPS**」。
   （手机「添加到主屏幕」长期使用、摄像头/剪贴板之类功能都需要 HTTPS）
4. 可选：站点 → 配置文件里给 `/api/` 段加 `proxy_read_timeout 120s;`（一次刷新很多账号时后端会慢一点）。

> 不用域名、只想 `http://服务器IP:8787` 直接用：把 `.env` 的 `HOST` 改成 `0.0.0.0`，重启，并在**安全组/防火墙**放行 8787。

---

## 第 7 步：上线后马上做

1. 浏览器打开 `https://你的域名/admin.html` → 用 `.env` 里的管理员登录 → 「修改我的密码」；
2. 后台「公告」标签页里写点内容（留空则统计页不显示公告卡）；
3. 忘了管理员密码时（命令行重置）：

```bash
cd /www/wwwroot/hpjyjmz/kimuzhi
node scripts/create-admin.mjs --list                 # 看现有用户
node scripts/create-admin.mjs admin 新的强密码        # 重置/创建管理员
```

---

## 以后怎么升级

```bash
cd /www/wwwroot/hpjyjmz/kimuzhi
git pull                    # 看到 "Already up to date." 就是没有新版本
```

然后到宝塔 **Node 项目里点「重启」**（改了后端代码必须重启），浏览器 **Ctrl+F5** 强刷一次绕开前端缓存。

`data/`（数据库）和 `.env`（配置）被 `.gitignore` 排除，`git pull` **永远不会覆盖**它们。

如果 `git pull` 被本地改动挡住（例如你手改过 `config/endpoints.json`）：

```bash
git update-index --skip-worktree config/endpoints.json   # 让 git 忽略这个文件的本地改动
```

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 启动就报 `Cannot find module 'node:sqlite'` | Node 版本太低。装 Node 24 LTS；Node 22.x 要加 `--experimental-sqlite` |
| `curl` 连不上 8787 | Node 项目没启动 / 端口填错 / `.env` 的 `PORT` 与面板不一致 |
| 手机打不开，电脑能开 | `.env` 的 `HOST` 还是 `127.0.0.1`，改 `0.0.0.0` 重启；或安全组没放行端口 |
| 页面能开但接口 502 | 反向代理目标写错（应是 `http://127.0.0.1:8787`），或后端没起来 |
| 数据库写入失败 `SQLITE_READONLY` / `unable to open database file` | `data/` 属主不对：`chown -R www:www data` |
| 改了 `.env` 没效果 | 没重启服务（`.env` 只在启动时读一次） |
| 公告保存了但统计页看不到 | 统计页要刷新；或浏览器缓存（Ctrl+F5） |
| 后端日志里 `[adapter] 接口A 返回失败` | 接口密钥/额度问题，检查 `.env` 的 `API_KEY` 和 `config/endpoints.json` |
